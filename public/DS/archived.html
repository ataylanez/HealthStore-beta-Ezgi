Hand-rolled NHS tab CSS Removed

During the NHS Design System migration the bespoke .nhsuk-tabs* rules in app/globals.css were removed in favour of the official nhsuk-frontend Tabs CSS. The same migration replaced hand-rolled badges, the bespoke skip link (.skip-link → .nhsuk-skip-link) and the bespoke footer with NHS components. See docs/NHS_DESIGN_SYSTEM_MIGRATION.md for the full mapping matrix.

Toggle buttons

One toggle control remains in the product: Add to compare (CompareToggleButton). It renders through components/ui/Button.tsx and is an NHS button with a pressed state. The Save toggle, the PDP utility cluster, the compare “lens” and the differences-only checkbox were all retired — see Archived.

Component
CompareToggleButton → Button variant="toggle" or variant="primary" (solid)
Used on
Catalogue result cards (solid) · product detail page title area (solid)
Provenance
NHS button styles; the pressed state is a HealthStore addition (NHS has no toggle button)

Add to compare

Label changes with state: Add to compare → Added (with a check icon). When the basket is full (four products) or the product is from a different condition area, the button becomes aria-disabled with a reason in title, stays in the tab order and shows a toast if pressed.

Accessibility

  • aria-pressed carries the state; the label text changes too (never icon-only).
  • Use aria-disabled, not disabled, so keyboard users can still reach the control and hear why it is blocked.
  • Minimum 44px target height.

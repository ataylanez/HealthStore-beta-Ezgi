Components

Navigation

The NHS header, the phase banner, the NHS breadcrumb and the back-to-top control. Together they express the site information architecture: Home is L1; About, Product catalogue, Comparison tool, Funding index and Resource library are L2 peers. All of them share the 960px nhsuk-width-container.

Header

The stock NHS nhsuk-header (components/Nav.tsx): NHS logo plus the service name “HealthStore”, a nhsuk-header__navigation row with the five commissioner links and an AI Advisor button, and the NHS “More” drop-down when links overflow. Inside the supplier portal the same header shows portal links instead (Dashboard, Product management, Published pages) and an nhsuk-header__account area with the supplier name and sign out.

The Comparison tool link carries a live count (.hs-nav-count) mirrored in its aria-label (“Comparison tool, 2 selected”). The current section is marked with nhsuk-header__navigation-item--current; “Product catalogue” owns the whole /catalogue and /apps branch so product pages keep a highlighted header item.

Phase banner

Directly under the header, inside the width container: the GOV.UK phase banner recoloured to NHS (PhaseBanner, tag “Alpha”) with a feedback link. NHS has no equivalent component.

Breadcrumb

The NHS nhsuk-breadcrumb via PageBreadcrumb. Home is prepended automatically; the current page is omitted, so the trail shows the path back only. On mobile NHS collapses it to a single “Back to [parent]” link (nhsuk-breadcrumb__backlink). It sits inside nhsuk-width-container above the nhsuk-main-wrapper--s, so the gap to the title is the same on every page.

Contents list (product pages)

Product detail pages use the NHS nhsuk-contents-list (PdpSectionNav) in a one-third column as their section navigation. See Product detail.

Back to top

BackToTop: a fixed primary button that appears after scrolling 400px on screens above the mobile breakpoint. Bespoke — NHS has no back-to-top component. Whether to keep it is an open design decision (noted in the Round 10 audit).

Accessibility

  • Header is the NHS <header class="nhsuk-header">; the navigation is a <nav> with a label and a skip link precedes it.
  • Breadcrumb uses the NHS ordered list; separators are CSS, and the mobile back link names its target.
  • The mobile menu toggle has an accessible label and the count badge is mirrored in the link's aria-label.

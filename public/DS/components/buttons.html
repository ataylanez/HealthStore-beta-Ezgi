On a coloured (accent) surface

For CTAs that sit inside a coloured callout (the express-interest pattern), use --on-accent: white fill, accent text.

<div style="background: var(--nhs-blue)">
  <button class="ds-btn ds-btn--on-accent">Express interest</button>
</div>

Toggle button (stateful)

Add to compare is the only stateful button left (CompareToggleButton → variant="toggle", or variant="primary" when solid). Blue-tinted when pressed, with the NHS 4px press shadow; shadow flattens on :active and when disabled. Set aria-pressed. The Save toggle and the PDP Share / Save / Compare utility cluster were retired — see Toggle buttons.

<CompareToggleButton appId={id} solid />

Disabled state

Disabled buttons use opacity-40 + cursor-not-allowed. <Button> applies it via disabled:opacity-40 disabled:cursor-not-allowed.

Default to native disabled. When a control must stay focusable and explain itself (e.g. “compare basket full”), use ariaDisabled and disabledReason on Button so the control stays in the tab order and shows a tooltip.

<Button
  variant="toggle"
  ariaDisabled={blocked}
  disabledReason="A maximum of 4 apps can be in the comparison tool."
  onClick={() => toggle(appId)}
>Compare</Button>

Accessibility

  • Use a real <button> for actions and <a> for navigation.
  • Icon-only buttons need aria-label; decorative icons get aria-hidden.
  • Toggles set aria-pressed; pending states set aria-busy and disabled.
  • Bordered secondary and toggle buttons use a 4px press shadow that matches their border colour (var(--nhs-blue)); borderless toggles use grey/dark shadows. Shadow removes on active press and when disabled.
  • Disabled buttons use real disabled at opacity-40 + cursor-not-allowed; only use the ariaDisabled + disabledReason escape hatch when the control must stay focusable, and always pair it with an explanation.
  • Focus ring is the global 3px yellow outline.

Do

  • Use one primary action per view.
  • Reuse .ds-btn variants instead of new inline styles.
  • Keep the 44px minimum target.

Don't

  • Re-hardcode #005EB8 / hover hex per button.
  • Style links to look like primary buttons unless they navigate.
  • Mix radius conventions across adjacent buttons.

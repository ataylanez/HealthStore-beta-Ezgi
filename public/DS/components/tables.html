Tables

All tables use the NHS nhsuk-table component. Two variants are in use: the plain table (deployment register, supplier portal status list) and the responsive table (nhsuk-table-responsive) for the comparison tool, which stacks cells under their column heading on small screens.

CSS
nhsuk-table, nhsuk-table-responsive, nhsuk-table__caption, nhsuk-table__head, nhsuk-table__row, nhsuk-table__header, nhsuk-table__cell
Used in
Comparison tool (6 tables), deployment register on the PDP, supplier portal statuses, funding tables
Not used
Horizontal-scroll grids, sticky headers, expandable rows (retired with the compare workspace)

Deployment register (PDP — NHS experience)

DeploymentRegisterTable: a short stats row (live sites, ICBs, pilots) above a plain nhsuk-table. The caption is visually hidden because the section heading already names the table. Status is carried by an nhsuk-tag, never colour alone.

Responsive comparison table

CompareNarrativeTables: products as columns, dimensions as row headers. Each data cell carries a hidden nhsuk-table-responsive__heading so that, below 769px, every cell is labelled when the table stacks. The first column is fixed at 18% so dimension labels align across the six tables.

Conventions

AspectConvention
CaptionAlways present; nhsuk-table__caption--m when visible, nhsuk-u-visually-hidden when the section heading already names the table
Row headers<th scope="row"> for the first column
Missing values“Check with supplier” in nhsuk-u-secondary-text-colour; never an empty cell or a dash
Statusnhsuk-tag with text, not colour alone
OverflowUse nhsuk-table-responsive to stack; do not scroll horizontally

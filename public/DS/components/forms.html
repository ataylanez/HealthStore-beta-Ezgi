Components

Forms & inputs

All form controls are stock NHS components: nhsuk-input, nhsuk-select, nhsuk-textarea, nhsuk-radios, nhsuk-checkboxes, nhsuk-file-upload, nhsuk-task-list. FormField wraps a control in the NHS form group with label, hint and error message and wires aria-describedby. Every form sits in a nhsuk-grid-column-two-thirds column and asks one question per page.

Question as page heading

On one-question pages the label is the h1: nhsuk-label-wrapper > h1 > label.nhsuk-label.nhsuk-label--l. A context caption (nhsuk-caption-l, e.g. the product name) goes above it.

<span class="nhsuk-caption-l">Luscii</span>
<h1 class="nhsuk-label-wrapper">
  <label class="nhsuk-label nhsuk-label--l" for="dtac">What is the product's DTAC status?</label>
</h1>

Select & textarea

Error state

Errors are announced twice, as NHS expects: an error summary at the top of the page that links to each field, and an nhsuk-error-message on the field itself (nhsuk-form-group--error, nhsuk-input--error).

Error: Enter an email address in the correct format, like name@nhs.net

Radios & checkboxes

Stock nhsuk-radios / nhsuk-checkboxes. The catalogue filter panel uses the --small modifiers. Groups are always a fieldset with a legend (visually hidden where the heading already says it).

<fieldset class="nhsuk-fieldset">
  <legend class="nhsuk-fieldset__legend nhsuk-u-visually-hidden">Condition</legend>
  <div class="nhsuk-radios nhsuk-radios--small">
    <div class="nhsuk-radios__item">
      <input class="nhsuk-radios__input" id="c-copd" name="condition" type="radio" value="copd">
      <label class="nhsuk-label nhsuk-radios__label" for="c-copd">COPD</label>
    </div>
  </div>
</fieldset>

File upload

NhsFileUpload renders the official NHS file upload with its drop zone (nhsuk-file-upload, initialised with the nhsuk-frontend JS). Used in the supplier portal for assurance documents.

Task list

SupplierOnboardingTaskList is the official nhsuk-task-list: each task a row with a link, a hint and a status. Completed tasks show plain text (nhsuk-task-list__status--completed); other states use an nhsuk-tag. See Supplier portal.

Buttons in forms

One primary nhsuk-button (“Continue” / “Save and continue”); secondary actions are links. Button groups use nhsuk-u-margin-* points, never ad-hoc flex gaps.

Accessibility

  • Every field has a programmatically associated <label>; hints and errors are joined with aria-describedby.
  • On submit with errors, focus moves to the error summary; each summary link focuses its field.
  • Radio and checkbox groups use fieldset + legend.
  • Never remove the NHS focus style.

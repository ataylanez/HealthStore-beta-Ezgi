1. Commissioning snapshot heading links

Segment headings that deep-link into a detail section — Indicative cost, Integration capability, Live NHSE sites — were rendered in primary text, so they didn’t read as links. They now use --nhs-blue with an underline, matching every other inline link. Non-linking headings (e.g. Funding) stay primary text.

2. New colour token — Blue tint-25

One GOV.UK colour is adopted for KPI / metric value text that needs a blue accent: Blue tint-25 (--blue-tint-25 / #5694CA). It is lighter than NHS blue so metric figures read as data, while full NHS blue stays reserved for links and controls. See Colour for the usage table.

3. KPI tile metric colour

KPI tile values previously rendered in NHS blue, which read as a link. They now default to --text-primary; where a blue accent is wanted (e.g. local-value tiles) the new --blue-tint-25 token is used, never full NHS blue. The 4px NHS-blue top keyline is unchanged.

4. PDP “On this page” sidebar moved left

On desktop the sticky “On this page” nav moved from the right of the main column to the left, so the reading order is nav → content. Grid columns changed from minmax(0,1fr) 14rem to 14rem minmax(0,1fr).

5. Chart panel — flat white NHS card

The chart panel shell moved to a flat white fill with square (4px) corners via --radius-card, matching the NHS primary non-clickable card. Previously it used --radius-lg on the tinted card token.

7. Evidence / publication card

Clinical publication cards dropped the coloured accent keyline and are now a plain NHS primary card (.hs-case-card--publication): white fill, 1px --border, square corners — so they read as reference material rather than a status signal.

8. Body copy size on dense PDP sections

Intro, stat labels, badges, outcomes and disclaimers in the NHS experience and local value sections were bumped to 16px (NHS body-s), the NHS minimum for body copy, so dense commissioner content stays legible.

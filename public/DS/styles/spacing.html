Spacing & layout

Spacing follows the NHS spacing scale (nhsuk-frontend/core/settings/_spacing.scss): a 4px base grid with points 0–9. Prefer the NHS spacing utilities (nhsuk-u-margin-*, nhsuk-u-padding-*) and the --space-* tokens. Where Tailwind is still used it must land on an NHS point; off-scale steps (12px *-3, 20px *-5, 28px *-7, fractional 2/6/10/14px) are avoided.

Page container — NHS width container

Every page sits in the NHS nhsuk-width-container: a centred 960px canvas with NHS gutters (16px on mobile, 32px from the tablet breakpoint). The header, navigation, phase banner, breadcrumb and footer share the same container so all edges line up. The 1280px .hs-page canvas used until Round 9 is archived.

Vertical rhythm — NHS main wrapper

Top and bottom page padding comes from nhsuk-main-wrapper, not from a bespoke wrapper. Pages with a breadcrumb or back link above the <main> use the --s variant so the title sits close to the breadcrumb.

Within a page, use NHS spacing utilities (nhsuk-u-margin-top-6, nhsuk-u-margin-bottom-4…) or the --space-* tokens. .hs-section (32→40px) remains for stacked home-page sections.

NHS grid

Columns come from nhsuk-grid-row + nhsuk-grid-column-*. Columns stack below the tablet breakpoint (769px). Tailwind grid-cols-* is reserved for things that are not page layout (chart internals, the tile strip inside the PDP).

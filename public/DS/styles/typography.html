Typography

Text is set with the NHS type styles from nhsuk-frontend (nhsuk-heading-*, nhsuk-body-*, nhsuk-lede-text, nhsuk-caption-*). Round 10 removed the hand-rolled heading classes (.page-title-h1, .hs-section-title), the retired 24px lede, uppercase letter-spaced labels and the Frutiger Light face.

Typeface

Family
Frutiger, Arial, sans-serif
Weights
400 (Regular) and 600 (Bold) only — no Light, no 500/700
Case
Sentence case everywhere; no text-transform: uppercase or letter-spacing
Tokens
--font-display, --font-body

Page title with caption

Where a title needs context (the supplier on a product page, the product on a portal edit page) the caption sits inside the <h1> so screen readers announce it with the title.

Luscii HealthtechLuscii

<h1 class="nhsuk-heading-xl">
  <span class="nhsuk-caption-xl">Luscii Healthtech</span>
  Luscii
</h1>
<p class="nhsuk-lede-text">Remote monitoring for long-term conditions…</p>

Heading colour

All heading levels default to --text-primary (NHS black, #212B32). NHS blue is not a heading accent — reserve it for links and interactive controls.

Links

Links are underlined at rest and lose the underline on hover (nhsuk-link behaviour). The previous hover:underline pattern is retired.

Do

  • Use nhsuk-heading-* / nhsuk-body-* classes; keep one nhsuk-heading-xl per page.
  • Put context in a nhsuk-caption-xl inside the h1, not in a separate grey line above it.
  • Set the smallest running text at nhsuk-body-s (16px desktop).

Don't

  • Use Tailwind text-xs/text-sm for labels or meta — they fall below the NHS scale.
  • Use uppercase + letter-spacing for labels or eyebrows.
  • Use weights other than 400 and 600.

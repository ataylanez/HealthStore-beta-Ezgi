Accessibility

This page documents the shared primitives every component should respect.

Focus state

A single global focus style is applied via :focus-visible: a 3px yellow outline with offset. Tab through the controls below to see it.

A focusable link 
:focus-visible {
  outline: 3px solid #FFD800;
  outline-offset: 2px;
  border-radius: 3px;
}

Skip link

A visually hidden skip link reveals on focus and jumps to #main-content (here, #ds-main). Press Tab from the top of the page.

<a class="nhsuk-skip-link" href="#main-content">Skip to main content</a>

Visually hidden content (.sr-only)

Use nhsuk-u-visually-hidden for labels that should be announced but not shown (e.g. the count on the Comparison tool header link). The Tailwind sr-only utility is equivalent but prefer the NHS class in new code.

The "(2 selected)" text is present for screen readers only.

Reduced motion

All transitions/animations collapse to near-zero under prefers-reduced-motion: reduce (card hover lifts, fade-ups, skeleton shimmer).

Print

The app ships a print stylesheet: header/footer/nav/buttons hidden, shadows removed, link URLs expanded. Relevant for the PDP "print / share" flow.

Component expectations

PatternRequirement
Icon-only buttonaria-label; decorative icon aria-hidden
Toggle buttonaria-pressed reflecting state; aria-busy while pending
Tabsrole="tablist", aria-selected, arrow-key roving focus
Modal/dialogrole="dialog", aria-labelledby, focus trap, Escape, restore focus on close
Alertrole="alert" (danger) or role="status" (info/warning)
Radio group<fieldset> + <legend> (may be sr-only)
Live updatesTransient action feedback goes through the global toast service (useToast()) — polite role="status" for success/info, assertive role="alert" for errors. Contextual counts (compare rows, catalogue results) keep their own aria-live regions.

Iconography

UI icons come from a single set, lucide-react.

1. Lucide React

The primary — and only — UI icon set (lucide-react): navigation, chrome and in-button icons such as Home, LogOut, Settings, PanelRightOpen, Menu, X, Bookmark, GitCompare, Mail, Share2. Outline style, sized via className="h-4 w-4".

import { Settings } from 'lucide-react'

<Settings className="h-3.5 w-3.5" style={{ color: 'var(--nhs-blue)' }} />

2. Custom HealthIcons SVGs

Bespoke condition glyphs in components/HealthIcons.tsx (6 icons + a ConditionIcon resolver). No longer imported by any component since the home relayout — listed on Archived as a candidate for removal. NHS chevron / arrow icons on cards and the contents list come from nhsuk-frontend SVGs.

Sizing & accessibility

ContextSizeNotes
Inline with text1em / 14–16pxAlign to baseline; use text-current
Nav / chrome16–20px (h-4 / h-5)Pair with a visible or sr-only label
Condition tiles24–40pxDecorative alongside a heading

Do

  • Mark decorative icons aria-hidden.
  • Give icon-only buttons an aria-label.
  • Colour icons with the accent token, not literal hex.

Don't

  • Mix outline and solid styles within one control group.
  • Convey meaning by icon alone without a text equivalent.

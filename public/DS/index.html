HealthStore Design System

Browser-readable record of the components, styles and patterns used across the HealthStore (NHS commissioner DTx store) product. HealthStore is built on the NHS Design System (nhsuk-frontend), with GOV.UK Frontend recoloured to NHS where the NHS DS has gaps, and a small set of bespoke components built to NHS principles. Since Round 10 every page uses the NHS 960px width container, grid and type styles. Tokens mirror app/globals.css.

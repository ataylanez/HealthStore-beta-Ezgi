Templates

What changed in the templates

The template set was last written on 5 August 2026. Since then every public page moved onto NHS page layouts. The eight templates are the same. What each one contains, and a few routes that were missing from the map, are not.

This note is for people designing pages and for the Wagtail handover. It says what the August descriptions got wrong, and what the template pages say now. The template overview and each template page have been updated to match.

What stayed the same

  • There are still eight templates: Home, Content page, Hub, Directory, Product listing, Product detail, EOI, Comparison tool.
  • Five are still CMS content (Home, Content page, Hub, Directory, Product detail). Three are still driven by product data or site functionality (Product listing, EOI, Comparison tool).
  • The supplier portal is still not a CMS template. It uses the same question-page layout as the expression of interest, and is described on the Supplier portal pattern.

The frame every template now shares

August pages were drawn as if each template chose its own width and its own heading style. They do not. Every template now sits in the same NHS frame:

  • The page is 960 pixels wide, the same width as the header, the navigation and the “Alpha” banner.
  • The breadcrumb, or the back link on a form, sits above the main area, so the gap to the title is the same on every page.
  • The page title is the NHS extra-large heading. The sentence under it is NHS lede text (the larger intro style), in sentence case.
  • Reading text, forms and the funding list sit in a two-thirds column. Side-by-side layouts use a one-third column beside it.

Template by template

T1 · Home

The hero is the NHS hero, inside the 960px width, with the headline in the two-thirds column and the illustration beside it. It is no longer a band that runs to the edges of the screen. “What the NHS HealthStore addresses”, “How it works” and the pathway cards are NHS card groups: equal-height cards in three columns that stack on a phone. The case-studies band is still marked as to be confirmed.

T2 · Content page

About and Cookies are unchanged as a type: title, lede, then sections of prose, all in the two-thirds column. The intro is lede text, not a small grey paragraph.

The August map missed the resource library’s inner pages. They are the same template:

  • Section indexes — Training and guidance, Preparing to recommend a DTx, Prior to patient appointment, During patient appointment, After a patient appointment. Each is a title, a lede, and a list of links.
  • The articles those lists point at. Each is a title and prose in the two-thirds column.

“Long-term management of a DTx” is a card on the resource library, but it does not have a page yet.

T3 · Hub

The catalogue and the resource library keep a title and lede in the two-thirds column, then an NHS card group. Cards are one-third wide and equal height. On the catalogue, pathways that are not available yet are secondary cards (a quieter style), in the same group as the live ones. The resource library has six cards, not four.

T4 · Directory

The funding index lists clickable funding cards down the two-thirds column. Open, upcoming and periodic opportunities share one list. Closed opportunities sit under their own “Closed (confirm current status)” heading. Editors still maintain the records one by one.

T5 · Product listing

Filters sit in a one-third column: condition as a single choice, supervision model as multiple choices, then an Apply button. Results are full-width NHS cards stacked in the two-thirds column, each with “View product details” and “Add to compare”. When nothing matches, the page shows NHS inset text (“No apps match your filters”), not an empty card. The related-content side list marked “to be confirmed” in August was never built, so it has been removed from the template. The filter panel is the side column.

T6 · Product detail

A product is no longer one long page with a sticky “On this page” sidebar. It is a small set of pages that share one frame:

  • An overview at /apps/[slug].
  • One page per section at /apps/[slug]/[section] — the problem, how it helps, local impact, what it could be worth, funding levers, assurance, implementation, NHS experience, how to buy, and resources.

The left-hand column is an NHS contents list. The page you are on is bold text; the others are links. The supplier’s name is a caption inside the product title. “Add to compare” sits with the title. “Express interest” stays at the bottom of the column. Section titles still come from one list, so the contents list and the headings cannot drift apart. The local-value model is still site functionality, not CMS copy.

T7 · EOI

This was already one web address per step. Each step now uses the shared frame: a back link, the question as the page title, NHS form fields, and a two-thirds column. If the answer fails checks, an error summary appears at the top and the field is marked. Check your answers is an NHS summary list. Confirmation is the green NHS panel. Question wording stays editable; the flow itself stays in site code. Supplier onboarding asks questions the same way, and stays out of this template set.

T8 · Comparison tool

The title and a short introduction sit in the two-thirds column. Below that, up to six NHS tables compare the chosen products, with products as columns. On a phone each cell is labelled with the product name, so the table does not scroll sideways. With nothing selected, the page shows a sentence and a link to the catalogue. There is no “compare by” switch and no “only differences” checkbox.

Where to read the detail

Each template page now describes the layout above. The design-system pages for spacing and layout, typography, product detail, discovery and comparison show the same patterns with the component names.
